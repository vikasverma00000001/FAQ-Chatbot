#  FAQ Chatbot

##  Project Overview

The FAQ Chatbot is an AI-powered conversational application designed to answer frequently asked questions intelligently. It helps users get quick and relevant responses through a simple and interactive chat interface.

The project demonstrates the use of Python, Generative AI, and Large Language Models (LLMs) to build an automated question-answering system.


##  Project Workflow

1. User enters a question in the chatbot interface.
2. The application processes the user's query.
3. The query is sent to the configured AI model.
4. The model generates a relevant response.
5. The chatbot displays the response to the user.
